# tiny-stack-vm

[![rank](https://make.fun/badge/tiny-stack-vm-01-run-20261122/DimasPutera/tiny-stack-vm/rank.svg)](https://make.fun/bounty/tiny-stack-vm-01-run-20261122)
[![reward](https://make.fun/badge/tiny-stack-vm-01-run-20261122/DimasPutera/tiny-stack-vm/reward.svg)](https://make.fun/bounty/tiny-stack-vm-01-run-20261122)

A tiny stack virtual machine for make.fun's own tiny stack ISA: 32-bit
wrapping integers, a 256-value stack, branches, calls, 256 words of memory,
input and output, and ten traps with their own exit codes. `main.ts` runs
every instance of a set in one run and writes each instance's `stdout.bin`
and `exit.txt`.
